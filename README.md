# Economic Conditions and Forced Displacement Trends in Venezuela (2006–2025)
<<<<<<< Updated upstream
This project examines trends in forced displacement and economic indicators in Venezuela from 2006 to 2025 using UNHCR Refugee Data Finder statistics and World Bank Development Indicators. It explores associations between economic conditions and displacement patterns without making causal claims.
